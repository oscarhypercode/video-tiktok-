# Fórmulas de guion (≈3,3 palabras por segundo; 50 s ≈ 160 palabras)

Reglas comunes: la primera frase es el gancho (sin "hola"), frases cortas, conectores de charla
("Y ojo:", "Pero lo más loco:", "Y no acaba ahí:", "De bonus:"), cifras redondas que se puedan mostrar,
cierre con pregunta para comentarios + "sígueme para más". Verifica cada dato.

## Top / lista (el más versátil)
"[Tema] hace/tiene cosas [adjetivo], y seguro no sabías estas [N]. Uno: [dato]. [explicación corta]. Dos: …
… Y de bonus: [dato extra]. ¿Cuál te sorprendió más? Déjalo en los comentarios y sígueme para más."
Escenas: gancho (xl) → "estas N" (golpe) → un `item` por punto con un visual distinto → bonus → cta.

## Datos curiosos de un tema
"¿Sabías que [dato más fuerte]? ¡[repetición corta]! [explicación]. Y ojo: [dato 2 con comparación].
Pero lo más loco: [dato 3 + consecuencia graciosa]. Y no acaba ahí: [dato 4]. ¡[remate]! Sígueme para más."

## Mito o verdad
"[Creencia popular]. ¿Mito o verdad? … [veredicto]: [explicación]. Siguiente: …"
Escenas: titular con la creencia → visual `sello` (MITO/VERDAD) en la palabra del veredicto → `dato` o `icono`.

## Explicador / cómo funciona
"¿Por qué [fenómeno]? Pasa en [N] pasos. Primero, … Después, … Al final, … Por eso [conclusión]."
Escenas: `pasos` que se marcan al decirse, `icono` animado para el concepto clave, `dato` para la cifra.

## Comparación X vs Y
"[X] o [Y]: ¿cuál [gana en algo]? En [criterio 1], [X] [valor] contra [valor] de [Y]. …"
Escenas: `comparar` por criterio (barras), presentador `pensando` → `sorpresa` en el resultado.

## Consejos / tutorial
"[N] trucos para [objetivo] que nadie te dice. Uno: … (por qué funciona). …"
Escenas: `item` + `iconos` o `pasos`; presentador `decidido`, gesto `señalar`.

## Historia / cronología
"En [año], [hecho sorprendente]. Pero la historia empieza antes: …"
Tema `historia`; escenas con `dato` para años (`"miles": false` para que 1492 no salga como 1.492) y `cita`.

## Motivación / cita
"[Frase gancho]. [Historia breve en 3 frases]. [La cita]. [Llamado a la acción]."
Tema `motivacion`; visual `cita` (las palabras se iluminan al decirse).
